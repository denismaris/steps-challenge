# Provocarea Pașilor 2026

A party-style reveal for our group's steps challenge: drum rolls, nervous sweating faces, tomatoes for last place, a "deal with it" winner with a money rain, and the final podium.

## Run it

```bash
npm install
npm run dev
```

Open the link Vite prints, then press **Space** to go forward.

| Key | Action |
| --- | --- |
| Space / → | next |
| ← | back |
| F | fullscreen |
| M | mute |
| T | more tomatoes (last place) |
| Home | back to start |

## Edit it

Everything (names, steps, quotes, photos, face gags, records, the winner song) is in [`src/config.ts`](src/config.ts).
Photos go in `public/photos/`, the winner song in `public/audio/winner.mp3`.
